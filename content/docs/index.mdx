This site documents two products:

- **Horus**, an open-source workflow manager for HPC and the cloud. You
  describe a pipeline as a set of tasks, in YAML or Python, and Horus runs them
  in dependency order. It moves data between stages, sends each stage to the
  compute you point it at, and shows live progress in your terminal.
- **Temple Compute OS**, the workflow platform built on Horus. It adds a
  visual workflow editor, run and campaign management, and shared projects.
